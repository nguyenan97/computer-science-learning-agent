## Plan a practical study day

The [study profile](references/study-profile.json) plans a seven-hour day including breaks, with a build route and a paper route. Paper reading produces annotations, a claim ledger, a reproduced result and a critique. Use the day for focused research: alternate explanations and worked traces with source reading, implementation, debugging, controlled experiments and a task in a different context. Each lesson gives flexible blocks with a useful output and a point to stop. Spend longer on an unclear foundation, shorten familiar material and leave time for breaks.

Start a new lesson with a few recall questions selected from earlier lessons by publication date. Try reconstructing an idea or predicting an output before opening its answer. When a result surprises you, find the smallest counterexample and explain what your earlier model missed. Worked answers are always available; no submission or saved progress is needed to read another lesson.

Add a topic, available tools or a shorter time budget when useful. The planner selects an uncovered eligible IUH master objective before doctoral objectives; an existing same-day lesson is reused. The agent writes complete Vietnamese and English lessons with C# or T-SQL labs, checks them and opens a PR for review. You normally merge the PR on GitHub; an explicit request can authorize the agent to merge this work.
