# Tiến độ học

State hoạt động nằm riêng: `.learning-private/learning-state.json`, hoặc workspace
ngoài repo đã chọn. Trang này không chứa record hay counter người học.

[Workflow](../references/learning-workflow.md) hướng dẫn init/validate/update.
[Example trống](../../state/learning-state.example.json) là template công khai;
[schema v2](../../state/learning-state.schema.json) định nghĩa field. Không commit
state hay bài làm thật vào repo công khai.
