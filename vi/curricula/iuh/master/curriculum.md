## Tóm tắt học phần

### Philosophy — Triết học `6012401`

**Mục tiêu**

- Xây dựng hiểu biết nền tảng về triết học phương Tây, phương Đông và Marxist.
- Phân tích mối quan hệ giữa triết học và các ngành khoa học.
- Hiểu vai trò của khoa học và công nghệ trong phát triển xã hội.

**Kết quả chính**

- Giải thích các nền tảng triết học chính trong học phần.
- Phân tích quan hệ triết học–khoa học và vai trò xã hội của chúng.
- Áp dụng tư duy triết học vào các vấn đề phát triển khoa học/công nghệ.

### English — Tiếng Anh `6011401`

**Mục tiêu**

- Ôn grammar, sentence structure và vocabulary ở mức B1.
- Luyện listening, speaking, reading và writing.
- Chuẩn bị cho đánh giá theo format B1 và nhu cầu giao tiếp ở bậc sau đại học.

**Kết quả chính**

- Trình bày thông tin cá nhân, tham gia discussion và xử lý các tình huống speaking thông dụng.
- Viết email, message và structured letter.
- Đọc hiểu tài liệu tương đương B1 bằng contextual/vocabulary strategy.

### Advanced Database — Cơ sở dữ liệu nâng cao `6001111`

**Mục tiêu**

Nghiên cứu các chủ đề relational database nâng cao và cách database system hoạt động dưới storage, query-processing và concurrent workload.

**Nội dung cốt lõi**

- File storage và organization.
- Indexing và hashing.
- Query optimization.
- Transaction management.
- Concurrency control bằng serializability, locking và timestamp.
- Recovery sau transaction, system hoặc storage failure.
- Distributed database, distributed storage, ưu và nhược điểm.

**Kết quả chính**

- Giải thích storage, indexing và hashing nâng cao.
- Phân tích query optimization problem.
- Quản lý transaction và reasoning về concurrency control.

### Computational Statistics — Thống kê tính toán `6001114`

**Mục tiêu**

Cung cấp nền tảng thống kê cho data analysis và data science.

**Nội dung cốt lõi**

- Exploratory Data Analysis (EDA).
- Probability và các distribution thông dụng: Binomial, Poisson, Normal, t, F, Chi-square.
- Confidence interval.
- Hypothesis testing.
- Analysis of variance (ANOVA).
- Linear regression.

**Kết quả chính**

- Áp dụng EDA cho dataset.
- Hiểu các probability distribution thường gặp.
- Tính và diễn giải confidence interval.
- Chọn và áp dụng hypothesis test phù hợp.

### Advanced Algorithms — Thuật toán nâng cao `6001127`

**Mục tiêu**

**Nội dung cốt lõi**

- Algorithm design và analysis.
- Graph algorithm.

- Approximation algorithm và approximation scheme.

**Kết quả chính**

- Phân tích time complexity và algorithm performance.
- Đánh giá thuật toán cho practical problem.

- Knowledge discovery / data-mining process.

- Classification.
- Association-rule mining.
- Clustering.
- Sequential-pattern mining.
- Maximal/closed frequent-set mining.
- Subgraph mining.
- Fuzzy-set và rough-set approach.
- Dùng software tool giải bài toán mining thực tế.

**Kết quả chính**

- Chọn mining technique phù hợp với dataset/problem.
- Đọc và hiểu research literature về data mining.

## Quan hệ curriculum hữu ích cho learning agent

Các quan hệ dưới đây đến trực tiếp từ prerequisite/co-requisite và curriculum layout:

- **Advanced AI → Advanced Data Mining**.
- **Advanced Database → Advanced Data Mining**.
- **AI / Machine Learning / Deep Learning → NLP**.
- **Statistics + Advanced AI → Pattern Recognition**.
- **AI + Deep Learning → IoT/modern connected-system applications**.
- **Scientific Research Methodology + Special Topic → chuẩn bị Master Thesis**.

## Các điểm không nhất quán của source được giữ lại

PDF chính thức có một số inconsistency về mã học phần. Repository dùng identifier trong program contents/curriculum diagram làm canonical identifier và ghi lại discrepancy tại đây:

- **Big Data Analytics** là `6001221` trong curriculum contents/diagram, nhưng detailed course page hiển thị `6201109`.
- **Master Thesis** là `6001229` trong curriculum contents/diagram, nhưng detailed course page hiển thị `66001229`.

Đây có vẻ là inconsistency của document; repository không âm thầm sửa lịch sử source.
