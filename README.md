# Computer Science through practice

[English](README.md) · [Tiếng Việt](vi/README.md)

Understand how programs work, choose useful algorithms and test engineering decisions with code. Each lesson explains the idea on this page, walks through an example, gives you a practical task and shows a reasoned solution. You can learn directly in the browser; source links and downloadable labs are there when you want to investigate further or run the experiments yourself.

## Start learning

1. **[Lesson 01 — Big-O and stable deduplication in C#](lessons/2026-10-05-cost-model/lesson.md).** Follow a small order-processing problem from a trace to a cost model, then compare a scan with hashing. Learn why one loop can do quadratic work, how to preserve order and equality, and how to read CPU/allocation measurements without overclaiming.
2. **[Lesson 02 — Boundary search and time windows](lessons/boundary-search/lesson.md).** Find the first position satisfying a condition in sorted data. Derive a loop invariant, handle repeated values correctly and use two boundaries to count events in a time window.

Start with Lesson 01 if you want to build your cost-analysis foundation. You can also open the topic that answers your current question. Each page ends with related reading and links to the previous or next available lesson.

## Plan a practical study day

For a full day, allow about seven hours including breaks. Alternate a short explanation and worked trace with source reading, implementation, debugging, a controlled experiment and a task in a different context. The suggested schedule is a guide: spend longer on an unclear foundation, shorten familiar material and stop an experiment when you have enough evidence to explain its limits.

Try predicting an output before looking at the answer. When a result surprises you, find the smallest counterexample and explain what your earlier model missed. Return later and reconstruct the idea without notes. The worked answers are always available, and you do not need to submit work to read another lesson.
