## Content and code review

Both languages were reviewed for meaning, prerequisite bridges, formulas, numeric
examples, source claims, command paths, output and experiment limits. The array
rank difference counts entries; an ordinary SQL SUM still needs matching values
without a stored summary. The simplified O(log N+r) covering and
O(log N+r log N) separate-lookup models explicitly assume bounded keys and
separate comparison work from cached physical I/O. They are not Lesson 04's
capacity-based pseudopolynomial bound or an optimizer approximation guarantee.

The aggregate uses parameter values and half-open bounds. Only enum-selected
access directives are interpolated. Empty SUM is normalized to zero. IDs are
unique and bounded 1-50000, tenants positive and Amount 0-1000, preventing total
integer overflow under the schema. Reversed windows fail; equal endpoints are
empty. A row at long.MaxValue cannot be included by a larger signed-long endpoint.
Each instance creates and removes only its own temporary directory. An SQL batch
conflict rolls back previously inserted rows in that transaction.

The dependency graph is pinned by project references and packages.lock.json:
SDK 10.0.401 with latestPatch policy, net10.0, Microsoft.Data.Sqlite 10.0.9,
SQLitePCLRaw.bundle_e_sqlite3 3.0.3 and SourceGear.sqlite3 3.50.4.5.
Locked restore and warnings-as-errors builds pass. The independent correctness
oracle is a C# predicate scan, not a second SQL query sharing the same index path.
The transfer cursor retains time and unique Id, uses explicit ORDER BY and avoids
time increment overflow; independent LINQ ordering verifies all event IDs.
Snapshot stability is an assumption of this exercise, not an HTTP implementation.

## Limits and PR publication

Finite tests support these fixtures and contracts, not all possible database engine
behaviors. Warm-cache local timing does not establish a cold-storage result, a
universal selectivity threshold, SQL Server plan/performance, production concurrency,
p99 latency or durable-storage guarantees. CPU scheduling, OS cache eviction and
storage-flush implementation are not controlled. A wider covering index need not
be slower than a thin one in every small run; one observed ranking is not a theorem.
SQL Server candidates, production authorization, HTTP snapshot semantics and stored
aggregate summaries were not executed. Browser/ZIP verification is local; the lesson
is not claimed live on Pages before merge. PR CI results are reported in the PR and
completion message after the workflows finish.
